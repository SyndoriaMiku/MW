# Fonts

- `roboto-*.woff2` — Roboto by Google (latin, latin-ext and vietnamese subsets,
  weights 400 and 700), SIL Open Font License 1.1. Medium (500) is the 400 face
  with embolden, see `src/shared/ui/fonts/roboto_medium.tres`.
- `material-symbols-rounded.woff2` — Material Symbols Rounded by Google (outlined,
  weight 400, no variable axes), Apache License 2.0. Icons are drawn by code point;
  the names used are listed in `M3.ICONS`.
